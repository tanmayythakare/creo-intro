03 · PERFORMANCE ARCHITECTURE

Engineered with Go. Zero bloat.

Crafted for speed, resilience, and native Windows Terminal ergonomics. No heavy node runtimes, no electron wrappers, no telemetry.

Go 1.23+ Runtime

Sub-200ms Execution

Compiled to a lean, self-contained native binary. Starts up instantly, evaluates dependency DAGs, and triggers terminal tabs before your eyes can blink.

< 180ms Cold Boot
14.8 MB Binary Size
0 kb Telemetry Sent
wt.exe Orchestration

Native wt.exe Chaining

Harnesses Windows Terminal's command-line protocol to spawn tabs with custom titles, working directories, and color accents in one atomic call.

wt.exe -w 0 nt -d ./api -t "Backend" ; nt -d ./web -t "UI"
Process Guardian

Transactional PID Registry

Records every spawned process tree in .creo/pids.json. When you run creo stop, all child process subtrees terminate gracefully.

PID 14280 (Clean) PID 19844 (Clean) PID 8412 (Clean)
Port Collision Sentinel

Pre-Flight Port Sentinel

Before launching any service, Creo verifies whether required ports (3000, 8080, 5432, etc.) are available. If a zombie process holds a port, Creo alerts you with the exact locking PID before crashing.

04 · WORKFLOW STAGES

From zero to ready-to-code.

Three declarative steps designed to remove setup friction completely.

01
creo init

Auto-Detect Architecture

Creo scans your repository 3 directories deep. It recognizes package.json, pom.xml, go.mod, Cargo.toml, and docker-compose.yml.

Detects 40+ Frameworks
02
creo.yml

Generate Clean YAML

Outputs a human-readable, version-controllable configuration file defining project name, service directories, startup commands, and workflows.

Version-Controlled YAML
03
creo up

Atomic Multi-Tab Launch

Launches an atomic Windows Terminal instance. All services boot simultaneously in organized tabs with full environment isolation.

Ready in < 180ms

Build your creo.yml live.

Select your stack components below to see how Creo models your microservice workspace using the real Go CLI schema.

Tip: Save this generated file as creo.yml in your repository root.

  name: my-app

services:
  frontend:
    path: web
    command: npm run dev
  backend:
    path: api
    command: go run main.go
  postgres:
    path: infra
    command: docker compose up postgres
  redis:
    path: infra
    command: docker compose up redis

workflows:
  dev:
    - frontend
    - backend
    - postgres
    - redis
